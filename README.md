# 🚀 Power BI Interactive Dashboard Project 📊
I’m excited to share the Mobile Sales Dashboard.

🔧 Project Workflow:

📥 Imported sales data from an Excel file into Power BI.

🧠 Explored and understood the dataset to identify useful insights.

🔄 Transformed the data using Power Query, where I:

Cleaned and shaped the data.

Created a custom calendar table for time-based analysis (MTD, YTD, Same Period Last Year).

🧩 Used Data Modeling to define relationships between tables.

📌 Key Features of the Dashboard:

KPIs for Total Sales (₹769M), Quantity Sold (19K), Transactions (4K), and Avg. Price (₹40K).

Interactive slicers for Brand, Model, Payment Method, and Month/Year.

Visuals:

Line chart for quantity trend across months.

Pie chart showing transactions by payment method.

Map visual to display sales distribution across Indian cities.

Bar charts for top mobile models and customer ratings.

Funnel, cards, and area chart for daily sales trend.

🔄 Page navigation using buttons and slicers for smooth interactivity.

🧮 Built dynamic measures and calculations using DAX.
